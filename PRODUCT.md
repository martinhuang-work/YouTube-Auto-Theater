# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Manifest V3 Chrome extension using plain HTML, CSS and JavaScript, as proposed and approved. No runtime dependencies, external services or build step for installation.

## Users and purpose

Desktop YouTube viewers who want videos to open in theater mode without repeatedly clicking the size button. A single persistent on/off preference controls automatic activation.

## Capabilities and constraints

Enable once per watch video; respect manual layout changes afterward. Off stops automatic switching and preserves the current layout. Handle YouTube's client-side navigation and delayed player controls. Do not act on Shorts, embedded players, fullscreen or mini player. Store only the local boolean preference. Public repository under martinhuang-work; maintain owner control over writes and merges.

## Brand commitments

YouTube Auto Theater Mode. Approved compact charcoal popup, red toggle, original widescreen icon, clear Enabled/Paused state, keyboard accessibility. Independent project, no implied YouTube endorsement.

## Evidence

The initial four-file prototype was supplied by the owner. Expanded files and reliability fixes were explicitly approved. Store approval is not yet obtained.
