# Contributions and ownership

The repository is public for transparency and bug reports. The owner, @martinhuang-work, controls which changes enter the project. Opening a pull request does not grant write or merge permission. The owner may decline changes or close pull requests without merging them.

Do not add analytics, remote code, broad site access, unrelated features or dependencies without first discussing the need in an issue. Keep the extension focused on automatic theater mode.

For a proposed fix, explain the user-visible problem, provide reproduction steps, run `npm run check` and `npm test`, and document live browser checks. Do not place credentials or personal browsing data in an issue, commit or test fixture.

No code license has been selected. Discuss substantial external contributions with the owner before submitting them.
