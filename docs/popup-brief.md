# Popup direction

## Scope and mode

Operate: a desktop Chrome extension popup, 336 CSS pixels wide. Adjust the viewing layout using two independent saved switches: automatic theater mode and optional live-chat hiding.

## Audience and action

People watching desktop YouTube. Open the toolbar popup, inspect the saved preferences, operate either switch, close it. Space toggles the focused native control. Both setting labels are clickable. Chat hiding defaults to off and includes replay chat. Turning it on closes an eligible current chat; turning it off stops automatic closing and preserves the current chat view. YouTube's native controls can reopen chat for the current video.

## Chosen direction

The user approved the proposed charcoal surface, red switch, original screen icon and concise state language. Direct code implementation of this specified small utility; no alternate visual-world exploration or generated bitmap comp. The Impeccable context launcher was unavailable and no existing design context was present.

## First viewport

Identity at the top, the established geometric screen that widens with the theater preference, then the theater switch and its explanation. Below a quiet divider, Hide live chat uses the same switch and clear on/off text, followed by one sentence about replays and manual reopening. Shared save/error feedback and the local-preferences footer finish the popup. The screen is a preference illustration, never a claim about the currently open tab. The October 21 addition extends the existing visual system; it does not replace the identity or illustration.

## Signature interaction

The screen outline widens with the switch, while Enabled changes to Paused and the supporting sentence explains the effect. Motion is disabled under prefers-reduced-motion. Errors restore the saved setting and expose Try again.

## Quality bar

Immediate state recognition, 44px control target, visible focus, readable contrast, stable geometry, no external fonts or network requests. Inspect enabled, paused, keyboard focus and storage-error states. No fabricated testimonials, usage claims, or live-tab status.
