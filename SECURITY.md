# Security

The extension requests only local preference storage and content-script access to desktop YouTube. It has no backend, external dependencies in the shipped extension, remote execution or analytics.

For a security issue, use GitHub's private vulnerability reporting feature if it is enabled on the repository. Otherwise, open a minimal issue asking for a private reporting channel without posting exploit details, secrets or personal data. Do not send private information to a public issue.

Supported code is the current default branch. Published store versions will be documented when available.
